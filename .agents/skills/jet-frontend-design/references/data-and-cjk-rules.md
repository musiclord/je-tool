# 資料密集畫面與繁體中文排版

只檢查本次改動涉及的項目。這份清單整合既有設計研究與 JET 現行方向；來源和原查核日期見 [sources.md](sources.md)。
`SKILL.md` 與 [前端說明](../../../../docs/jet-frontend-description.md) 決定產品樣式，通用建議不覆蓋使用者裁定。

## 版面與文字

- 用位置、間距、字重與表面明度建立層級，同組靠近、不同組拉開。先分組再決定是否需要框線。（Windows、interface-design）
- 使用 `app.css` 的字級、間距與圓角變數，不為每個元件另寫數值。flex 和 grid 子項需能縮小，長字串不能撐破容器。（impeccable）
- 一般文字至少 12px，中文不加字距、不用斜體或全大寫。字體、行高與英數標點分工沿用現行樣式。（Windows、W3C clreq）
- 一般文字對比至少 4.5:1，控制項、圖示與焦點至少 3:1；玻璃需用可能經過的背景檢查，不能引用舊測量當新證據。（WCAG、Vercel）
- 狀態至少再有文字、符號或形狀，不能只靠顏色。（Carbon）

## 表格與數字

- 所有表頭文字靠左、單行、穩定高度。長名稱保留完整內容的查看方式，表格在自己的容器內水平捲動。
- 金額與筆數資料格靠右，使用等寬數字與一致小數位；畫面金額沿用 `Ui.money` 的兩位小數和千分位。（Primer、JET 現行格式）
  數字欄只取內容需要的寬度，靠左的標題與靠右的數字留在同一個窄欄，避免標題和數字分在欄的兩端。
- 明細每頁最多 200 筆，欄位配對來源資料也適用。超過一頁時左下角只放左箭頭、`目前頁數/總共頁數` 與右箭頭；只有一頁時不顯示。
  總頁數依完整結果筆數計算，箭頭有無障礙名稱和正確的端點停用狀態。
- 初次檢視即載入第一頁，換頁取代本頁，不以「載入更多」累加。檢查 0、1、200、201 筆、最後一頁與查詢條件改變。
- 排序必須先作用於目前查詢範圍的完整資料，再分頁。可排序表頭提供正確 `aria-sort`；未實作完整排序時不顯示排序操作。
- 固定表頭不能遮住焦點。長欄名、大金額與窄視窗都要可讀，數字不從中間斷行。

表頭與分頁依使用者 2026-10-16 本輪要求；其餘參考 Carbon、Primer 與 JET 的有界資料架構。實際完成狀態查現行計畫。

## 表單、狀態與焦點

- 標籤直接可見，placeholder 只放範例。同一操作全產品使用同一名稱。（Vercel、impeccable）
- 錯誤說明失敗動作、已知原因與可行下一步；保留已輸入內容。新增阻擋前，依 `AGENTS.md` 核對是否有業務依據。
- 區分尚未開始、沒有符合結果與查詢失敗；不要把失敗顯示成零筆。（Carbon）
- 按鈕處理中保留原文字與位置，載入提示沿用共用元件，不為局部畫面另訂時間規則。
- 使用原生 button 與適當的 `aria-pressed`、`aria-describedby`。可操作元素有可見焦點；重繪、切頁與關閉對話框後焦點仍有合理位置。（Vercel）
- 鍵盤操作、窄版與失敗重試按實際改動選測，不把視覺檢查當成業務驗證。

## 材質與動態

- 內容保持不透明；浮動功能層才使用玻璃，文字對比與不透明退路一起檢查。（Apple）
- 沿用 `JetMotion` 和共用曲線。優先動畫化 transform 和 opacity；展開收合需要版面移動時使用既有高度動畫，不另造例外。（Apple、Chrome）
- 連續操作可打斷動畫，操作不能等待動畫完成；表格捲動與儲存格點選不加裝飾動態。（Apple、interface-design）
- 流程選取維持原尺寸平移，加入標籤走直線，玻璃操作保留輕微彈性。這些依 JET 裁定，不能一概改成無回彈。
- 減少動態、高對比與視窗失焦時仍有清楚的狀態回饋。沿用現行停用轉場方式，不用極短動畫模擬關閉。（JET 現行實作）

更動 `text-autospace`、全形標點壓縮或全產品字型時，先確認 WebView2 的實際顯示與本輪授權；這類全域排版不隨小改順便調整。
