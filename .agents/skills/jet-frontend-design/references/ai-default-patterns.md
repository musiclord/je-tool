# AI 預設樣式清單

這份清單補充 `SKILL.md` 的禁止清單：每一項寫出它長什麼樣、誰點名的，以及 JET 目前的狀態。
清單會持續擴充。每輪看完截圖，發現新的預設樣式就加一列，寫明日期與在哪個畫面看到。
出處的網址與授權在 `sources.md`。

## 為什麼要逐項點名

Anthropic 的 Opus 4.8 與 Opus 5.5 提示指南都說，模型沒有設計方向時會退回固定的預設；
籠統要求「不要用米色」或「做得乾淨一點」，通常只是換到另一組固定配色。有效的做法是指定具體替代方案，
或先提出幾個方向讓使用者選，再逐項點名要避開的樣式。社群的 PR #1806 實測 21 頁樣本：
點名禁止膠囊按鈕後，出現頁數從 10 降到 0；沒有點名的斜體強調字與等寬小標則沒有變化。

## 例外怎麼處理

使用者明確指定其中一種樣式時照做，並把原話與日期寫進現行計畫與 `docs/jet-frontend-description.md`。
例如暖紙畫布與 Liquid Glass 式的玻璃是使用者 2026-10-11 指定的；同一天使用者也否定了靠漸層與高光做出立體感的玻璃。
2026-10-12 使用者又要求整個 JE Tool 帶有 Liquid Glass 的質感，所以例外是「浮在內容上的功能層用玻璃，光只在 1px 的邊上」，仍不包括漸層填色與跟著指標的高光。沒有這種指定時，只能用 JET 設計簡報裡的具體理由說明為什麼要用；
說不出理由就不用。
