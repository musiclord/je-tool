圖表只放在 [`2026-10-21/`](2026-10-21/README.md) 這一個目錄，目錄以重繪日期命名，內容是 2026-10-21 依固定快照重繪的

這些圖依據 2026-10-15 與 2026-10-16 的未提交工作檔快照，沒有更新到之後的產品修正。精確行為仍以現行程式與測試為準；
文字規格見[系統規格](../jet-guide.md)。

## 怎麼讀

循序圖與 LikeC4 用線型區分三種呼叫證據。直接呼叫表示編譯時目標是具體方法；介面呼叫只確定介面方法，
圖上寫的實作類別是依 AppCompositionRoot 的建立位置推論；間接觸發是 action 字串、WebMessage、委派或延遲串流，編譯器看不到目標。
所有連線都是靜態證據，沒有執行期觀察。循序圖只畫標題寫明的情境與分支，沒畫的分支寫在圖下方的卡片。

類別圖只畫編譯時存在的依賴、實作與繼承。資料表關聯圖的線是程式在 SQL 裡使用的連接欄位；這批 SQLite 建表定義沒有宣告外鍵。
SQLite 的 27 張表、164 個實體欄位列在[資料表欄位](2026-10-21/schema.html)頁。

## 已有的檢查

執行 `pwsh -NoProfile -File tools/verify.ps1 -Command Documentation` 時，除了文件連結與文字檢查，也會核對圖表目錄的檔案雜湊與來源版本。
圖表檢查涵蓋 174 條連線與 48 條類別關係，包括每條線都有依據、線型和證據種類一致、回傳對應到呼叫，以及匯出檔不含本機路徑。
合成案例會檢查依賴被誤寫成繼承、介面目標被換成未證實的實作、實作推論缺少組裝證據，以及沒有觀察紀錄卻宣稱已執行等情況。

這不是業務正確性檢查。業務流程的完整語意仍須閱讀來源，並依需要執行有明確輸入和預期結果的測試。
工具版本與檔案清單在圖表目錄的 `manifest.json`。
