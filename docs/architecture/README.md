# JET 架構與規格圖表

從[離線圖表入口](diagrams/index.html)查看系統架構、資料流、類別介面、業務流程與部署方式。把儲存庫下載到本機後，
直接開啟 HTML 即可；閱讀不需要安裝繪圖工具，也不需要啟動 JET。

入口左邊選圖，「這張圖的線」列出每一條線的依據，點一條線會跳到它的程式位置與摘錄。線型、方框顏色與各類圖怎麼讀，
寫在圖表目錄的[閱讀說明](diagrams/README.md)。頁面和圖面跟著系統的深淺色設定切換；在 LikeC4 圖裡手動切換過深淺色時，它會記住那次的選擇。

圖表固定放在 `diagrams/` 這一個目錄，內容是 2026-10-22 重繪的 7 個 LikeC4 視圖與 18 張 Archify 圖，
依據提交 `07b97b3` 的程式快照，不含之後的修改。之後每次重繪都直接覆寫這個目錄，不另開版本，
前一版留在 Git 歷史。精確行為仍以現行程式與測試為準；文字規格見[系統規格](../jet-guide.md)。

## 已有的檢查

執行 `pwsh -NoProfile -File tools/verify.ps1 -Command Documentation` 時，除了文件連結與文字檢查，也會核對圖表目錄的檔案雜湊與來源版本。
圖表檢查涵蓋 174 條連線、48 條類別關係與類別圖上的 43 個成員，包括每條線都有依據、線型和證據種類一致、回傳對應到呼叫、
每個成員都有宣告位置，以及匯出檔不含本機路徑。
合成案例會檢查依賴被誤寫成繼承、介面目標被換成未證實的實作、推論出的實作找不到 AppCompositionRoot 的建立位置，以及沒有觀察紀錄卻宣稱已執行等情況。

這不是業務正確性檢查。業務流程的完整語意仍須閱讀來源，並依需要執行有明確輸入和預期結果的測試。
工具版本與檔案清單在圖表目錄的 `manifest.json`。
