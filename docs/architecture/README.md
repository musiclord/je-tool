# JET 架構與規格圖表

從[離線圖表入口](2026-10-16/index.html)查看系統架構、資料流、類別介面與部署方式。把儲存庫下載到本機後，
直接開啟 HTML 即可；閱讀不需要安裝繪圖工具，也不需要啟動 JET。

## 這一版包含什麼

| 內容 | 範圍 |
|:---|:---|
| LikeC4 | 六個架構、元件協作與本機配置視圖。 |
| Archify | 第一輪四張類別與業務圖，第二輪十四張循序、資料流、類別、ERD、部署與維護圖。 |
| 資料表 | SQLite 的 27 張表、164 個實體欄位；邏輯關聯與資料庫約束分開說明。 |
| 來源 | 選定的程式摘錄、檔案雜湊、24 處呼叫對照及 17 組類別關係。 |

這批圖依據 2026-10-15 與 2026-10-16 的未提交工作檔快照。這次依使用者要求先收錄原圖，
沒有重繪，也沒有把它們更新成同日稍後的產品修正。畫面入口會持續顯示這個限制。
精確行為仍以現行程式與測試為準；文字規格見[系統規格](../jet-guide.md)。

循序圖表示選定情境，不能推論每次操作都走相同路徑。介面實作、編譯時呼叫目標與實際觀察到的呼叫
是不同證據。這批研究沒有執行業務流程，維護程序也只是草案。

## 已有的檢查

執行 `pwsh -NoProfile -File tools/verify.ps1 -Command Documentation` 時，除了文件連結與文字檢查，
也會核對這批檔案的雜湊、來源版本及 17 組類別關係。合成案例會檢查依賴被誤寫成繼承、
介面目標被換成未證實的實作，以及沒有觀察紀錄卻宣稱已執行等情況。

這不是涵蓋所有圖種的業務正確性檢查。LikeC4 模型、循序與業務流程的完整語意仍須閱讀來源，
並依需要執行有明確輸入和預期結果的測試。原始工具版本與檔案清單在[圖表清單](2026-10-16/manifest.json)。
