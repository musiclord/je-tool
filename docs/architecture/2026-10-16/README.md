# 固定快照圖表

開啟 [圖表入口](index.html)。原圖與候選 JSON 未重繪，LikeC4 模型也保持原樣。離線 HTML 中的本機來源連結已改為相對連結，避免帶入私人絕對路徑。

這批圖依據 2026-10-15 與 2026-10-16 的未提交來源快照，保留當時的分析結果。它們沒有更新到本次產品修正；程式現況仍以 src 與測試為準。循序圖描述選定情境，不表示每次操作都走相同路徑。

本輪只保存閱讀成果、選定關係與必要來源摘錄。沒有收入工具安裝、套件快取、私人案件、索引資料庫或整份程式快照。

## 驗證的邊界

原研究已完成圖表工具與瀏覽器檢查。納入儲存庫後另核對檔案雜湊、來源摘錄、本機連結及 17 組類別關係的種類。
這不是全部圖表的業務正確性證明；LikeC4、循序圖與業務說明仍須人工查證，沒有執行期觀察。
