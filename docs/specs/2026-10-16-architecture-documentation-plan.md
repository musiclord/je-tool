更新日期：2026-10-21
狀態：依固定快照重繪的 6 個 LikeC4 視圖與 18 張 Archify 圖已完成，並依使用者裁定取代原本的圖表目錄。使用者同日指示不另跑測試，直接提交並推送。

## 目標與本輪交付

開發者從離線入口查看系統架構、資料流程、類別介面與業務模型，並能回查程式證據。
2026-10-16 的一輪收錄原圖、可編輯模型、來源摘錄與 17 組類別關係的檢查，依當時裁定已提交並推送。
2026-10-21 的一輪沿用同一份 RepoWise 與 Roslyn 證據和固定快照，重繪全部圖表，分清編譯時目標、可能呼叫與實際執行。
重繪成果放在 [`docs/architecture/2026-10-21/`](../architecture/2026-10-21/README.md)，取代原本的 `docs/architecture/2026-10-16/`；
`docs/architecture/` 只保留這一個以重繪日期命名的圖表目錄，前一版留在 Git 歷史。

本輪不重新索引程式，不更新到快照之後的產品修正，也不改產品程式或業務邏輯。
完整分層 DFD、所有 action 的追溯、其他資料庫結構與正式部署手冊不列為完成條件。公司審查要求尚未確認，DocFX 暫緩。

## 讀圖的人會看到什麼

維護者開啟 `docs/architecture/2026-10-21/index.html`，左側依架構總覽、循序圖、業務流程、資料流、類別與介面、資料表關聯、
部署與維護分組選圖。入口上方說明這批圖的快照範圍，以及四種線條的意思：直接呼叫、介面呼叫、間接觸發與回傳。
每張圖旁有「這張圖的連線證據」，點進去可看到每條線的編譯時目標、介面背後的實作如何被建立、引用哪些已核對事實，
以及「未觀察執行」。查不到依據的線不會出現在圖上；檢查程式發現線型和證據種類不一致時，文件檢查失敗。

## 完成條件與驗證

- `docs/architecture/` 只保留 `2026-10-21/` 一個圖表目錄，前一版留在 Git 歷史。可編輯模型、候選 JSON、來源證據與離線入口都在這個目錄。
- 每條線都有可回查的依據，沒有任何一條標成已觀察執行；循序圖寫明情境與條件。
- 離線閱讀不載入外部資源，本機連結有效，匯出檔不含本機絕對路徑。
- 文件檢查能拒絕線型與證據種類不符、少了證據的線、沒有組裝證據的實作推論，以及沒有觀察卻宣稱已執行。
- `pwsh -NoProfile -File tools/verify.ps1 -Command Documentation` 通過後，完整回讀修改段落。

本輪只改文件與文件工具，沒有執行 Build、Public、Gui、Excel、Provider 或 PrivateCase，也沒有啟動 JET 或 SQL Server。
Archify 3.1.0 執行時提示有 3.2.0 可用，本輪沒有升級。
