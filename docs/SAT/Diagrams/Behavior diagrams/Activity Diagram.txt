@startuml
' JET 1.0.0.0 活動圖。範圍：審計員在「資料驗證與測試」步驟執行資料驗證，至進入「進階條件篩選」為止。
' 表示法：UML 活動圖。括號內的英文是前端送出的 action 名稱。
title JET 活動圖：「資料驗證與測試」的作業流程

|審計員|
start
:輸入資料可靠性測試抽樣筆數，\n執行資料驗證（validate.run）;
|JET|
if (前置檢查通過？) then (否)
  :顯示原因，不執行資料驗證：\n抽樣筆數非 1 至 1,048,524 的整數、\n另一項作業執行中，或 GL 欄位配對未確認;
else (是)
  :開始資料庫交易，統計分錄筆數、\n借貸合計與金額分布;
  if (已匯入 TB，且 TB 欄位配對已確認？) then (是)
    :執行完整性測試的\nGL 與 TB 逐科目比對;
  else (否)
    :完整性測試的 GL 與 TB 逐科目比對\n記為無法執行，並記錄原因;
  endif
  :執行借貸不平測試、資料可靠性測試、\n資料缺漏輔助檢視與總帳日期空白檢查;
  :判定各項結果（含存入筆數與合計核對），\n儲存驗證結果並提交交易;
  :產生資料驗證報告、資料可靠性抽樣清單\n與科目配對範本（export.validationReports、\nexport.accountMappingTemplate）;
|審計員|
  :查看各項結果、\n差異提醒與明細;
  note right
    存入筆數與合計核對未通過、
    GL 與 TB 逐科目比對無法執行
    或有差異時，JET 顯示提醒，
    不鎖定後續步驟。
  end note
|JET|
  if (驗證結果存在、未過期且完整？) then (否)
    :鎖定「進階條件篩選」並顯示原因；\n須重新執行資料驗證;
  else (是)
|審計員|
    if (執行預篩選？) then (是)
|JET|
      :執行預篩選（prescreen.run）;
    else (否)
    endif
|審計員|
    :進入「進階條件篩選」;
  endif
endif
|JET|
stop
@enduml
