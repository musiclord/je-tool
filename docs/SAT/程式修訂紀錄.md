JET 尚未正式發布。目前的功能與修正合併視為同一個首次評估版，不把開發期間每次推送列成發布版本。

| 範圍 | 本次內容 |
|---|---|
| 案件與資料 | 使用 SQLite 建立本機案件，匯入總帳與試算表並確認欄位配對。 |
| 審計作業 | 完整性、借貸不平、空白資料及可靠性測試，並提供預篩選與條件篩選。 |
| 報告與底稿 | 產生 Excel 報告；正式底稿保留歷次匯出。 |
| 本輪修正 | 可靠性樣本預設 59 筆，可自行調整。借貸別配對標示「借貸代碼至少填一個」。 |
| 底稿文字 | 分錄編製人員說明 A4 改為「此處底稿係記錄分錄編製人員資訊」；資料預先整理之說明 A3 留白。檔案欄位資訊不再由程式寫入 V.2019。 |

## 如何保留修改紀錄

Git 保存已提交的程式差異，審查者可以查看修改前後的內容；本文件只說明功能範圍與重要修正，不逐行複製程式。審查意見及測試結果分別留在 Code Review.xlsx 與測試紀錄表.xlsx。

公司選定送審程式後，再填寫下表。若送審檔包含尚未提交的修改，單靠 Git 提交編號無法識別全部內容，應先整理成可追溯的送審來源。本輪沒有建立提交或發布版本。

| 項目 | 送審時填寫 |
|---|---|
| 首次評估版名稱 | 待填 |
| 原始碼位置與 Git 標籤或提交 | 待填 |
| 發布檔位置 | 待填 |
| 測試與審查紀錄 | 待填 |

後續更新如何編號、哪些改動需要重新評估，由公司程序決定，本次不預設主要或次要版本制度。
