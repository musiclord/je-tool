# JET 使用說明

## 1. 簡介

JET 是協助審計員執行分錄測試的 Windows 桌面工具。審計員匯入受查者提供的總帳（GL）與試算表（TB）後，依六個步驟完成欄位配對、資料驗證、預篩選與條件篩選，最後匯出 Excel 格式的工作底稿。

JET 在使用者電腦上執行，案件資料存放在本機的 SQLite 資料庫，不需要另外安裝資料庫，審計作業不需要連線 AI 服務或遠端資料庫。

## 2. 系統需求與安裝

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 11，64 位元 |
| WebView2 Runtime | JET 用它顯示畫面；公司電腦需確認已安裝 |
| 使用者權限 | 以一般使用者操作為目標，送審前在公司電腦實測 |
| 匯入 Access 資料表 | 需要電腦已有 Microsoft Access Database Engine（ACE 16，64 位元）；其他檔案格式不需要 Office |

JET 不需要安裝程式。取得發布資料夾後，將整個資料夾放到電腦上，執行其中的 JET.exe 即可。

發布資料夾內的 wwwroot 與 Templates 必須和 JET.exe 放在一起，不可只複製 JET.exe。

## 3. 使用方式

進入案件後，畫面左側列出六個步驟，中央是目前步驟的操作區，右側可展開資料預覽。

| 步驟 | 操作內容 |
|---|---|
| 1. 建立案件 | 輸入案件名稱與查核期間，程式自動建立 SQLite 案件。 |
| 2. 匯入資料 | 匯入總帳明細，以及需要的試算表、授權編製人員清單、國定假日與補班日。總帳與試算表支援 Excel（.xlsx、.xlsm、.xls）、文字檔（.csv、.txt）與 Access 資料庫（.mdb、.accdb）。 |
| 3. 欄位配對 | 指定來源檔每一欄對應的 JET 欄位，例如傳票號碼、總帳日期與金額，確認後建立標準化資料。選「借貸別」時，借方或貸方代碼至少填一個。也可按「由底稿匯入欄位」，從舊版 IDEA JET 或新版 JET 的工作底稿帶入草稿；其他有配對紀錄的 JET 報告也可使用。看完要重選的項目並補選後，按「確認配對」才儲存。 |
| 4. 資料驗證與測試 | 執行完整性、借貸不平、空白資料及可靠性測試，並完成科目配對。可靠性抽樣預設 59 筆，可在執行前修改；分錄不足時全部抽出。預篩選可視需要執行。 |
| 5. 進階條件篩選 | 組合篩選條件，預覽符合條件的傳票與分錄，確認後儲存成篩選情境。 |
| 6. 匯出底稿 | 選擇要匯出的報告，產生工作底稿與各項報告。 |

已有篩選情境時，修改前面步驟的資料會清除後面步驟的設定，相關報告標示為過期，需要重新執行。已匯出的檔案不會被改寫。

長時間作業進行時，畫面會顯示目前狀態，並可隨時取消。

## 4. 輸出檔案

| 檔案 | 產生步驟 | 說明 |
|---|---|---|
| 資料驗證報告 | 第 4 步 | 完整性測試、借貸不平測試與空白資料檢查的結果。 |
| 預篩選報告 | 第 4 步 | 預篩選程序的結果。 |
| 資料可靠性抽樣清單 | 第 4 步 | 資料可靠性測試抽出的樣本。 |
| 科目配對範本 | 第 4 步 | 以 Excel 填寫科目分類的工作檔，填好後匯回 JET。 |
| 條件篩選報告 | 第 5 步 | 篩選情境命中的傳票與分錄。 |
| 工作底稿 | 第 6 步 | 正式輸出。每次匯出都產生新的版本檔，舊版本保留不變。 |

工作底稿以外的報告可以重新產生，每次匯出會覆蓋同名檔。

## 5. 案件資料

- 案件預設存放在使用者資料夾下的 JET 資料夾（%USERPROFILE%\JET），每個案件一個資料夾。
- 要搬移案件或交給其他同仁時，先正常關閉 JET，再複製整個案件資料夾。請勿直接開啟位於同步資料夾或共用位置上的案件，這種用法尚未驗證。
- 沒有試算表時仍可完成各步驟，只有總帳與試算表的逐科目比對無法執行，報告會寫明原因。
- 沒有儲存篩選情境時也能匯出工作底稿，篩選相關的工作表只保留表頭。

## 6. 使用者身分

JET 以目前登入 Windows 的帳號識別操作人員，不需要另外登入。建立案件時記錄的建案者與各項操作的執行者，都取自 Windows 帳號。

## 7. 常見問題

**Q1. 匯出時出現「報告檔無法寫入」，該怎麼處理？**

通常是報告檔正在 Excel 中開啟，或檔案設為唯讀。請關閉開啟該檔案的程式，確認有寫入權限後重新匯出。

**Q2. 為什麼重新匯出後，舊的工作底稿沒有更新？**

工作底稿是正式輸出，JET 不會覆寫已匯出的底稿。重新匯出會產生新的版本檔，第 6 步的「工作底稿版本紀錄」列出所有版本。

**Q3. 修改匯入資料或配對後，篩選情境不見了？**

篩選結果依賴前面步驟的資料。資料或配對改變後，原本的篩選結果不再正確，所以 JET 會清除篩選情境，請重新設定。

**Q4. 回報問題時需要提供哪些資訊？**

請提供錯誤訊息的畫面截圖、發生問題前的操作步驟，以及畫面左下角「訊息」區的「複製紀錄」內容。
