## 1. 本次檢查

本次檢查對象是 JET 首次評估版的 SQLite 程式與產品套件，供 ITS 與 NITSO 評估。檢查日期為 2026-11-06，對象仍是開發中工作目錄，尚非公司核准的發布檔。

已執行產品 NuGet 套件漏洞查詢，並檢視 SQL 查詢輸入、WebView2 訊息通道及報告檔案處理。沒有執行完整滲透測試、CodeQL、秘密掃描或公司環境查核。本文件不代表資安核准。

## 2. 環境與套件

JET 使用 .NET 10、WebView2 與 SQLite，在 Windows x64 電腦執行。本次開發檢查環境為 Windows 26H2（組建 26300.9818）、.NET SDK 10.0.402 與 PowerShell 7.6.9。這不是公司部署環境。套件查詢依專案現有還原清單，包含直接及間接引用，未重新還原套件。查詢來源為設定的 NuGet 套件來源；原始結果保存在 source/security-check.json。

| 項目 | 本次結果 |
|---|---|
| 產品套件公開漏洞查詢 | 查詢成功，未列出已知漏洞。這表示查詢當時的資料庫沒有回報，不保證不存在漏洞。 |
| SQLite 套件 | SQLite 3.53.4。套件說明標示前三段版本就是其原生 SQLite 版本。 |
| SQLitePCLRaw.bundle_e_sqlite3 | 3.0.5。完整依賴及授權見第三方元件.xlsx。 |
| WebView2 SDK | 1.0.4258.31。實際 Runtime 由公司電腦提供，送審時需另查版本。 |
| 公司環境 | Windows 更新、WebView2 Runtime、防毒、檔案權限及正式發布內容尚待確認。 |

查詢命令：

```
dotnet package list --project src/JET/JET/JET.csproj `
  --no-restore --vulnerable --include-transitive `
  --format json --output-version 1
```

CVE-2025-6965 的 GitHub 公告列為高風險，CVSS 4.0 分數為 7.2。舊 SQLitePCLRaw.lib.e_sqlite3 2.1.11 及以前版本受影響，SQLite 的修正版本為 3.50.2。本次清單中的 SQLite 3.53.4 已高於該修正版本；正式送審仍需核對發布檔實際載入的版本。

## 3. 原始碼檢視結果

| 範圍 | 目前做法與結論 |
|---|---|
| SQL 輸入 | 篩選值使用參數傳入；欄位與排序由程式允許的清單決定。已查看 FilterSqlFragmentPlan、FilterSqlPlanBinding、FieldValueConditions 與 KeysetPaging。2026-11-09 開頭符合與結尾符合改成可以填多個值，這晚於本次檢查；修改後每個值仍各自用參數傳入，個數受每條條件的上限限制。 |
| WebView2 畫面 | Form1 限定內建網址，阻擋外部導覽與新視窗，停用網頁直接存取主程式物件。 |
| 操作訊息來源 | JetWebMessageBridge 沒有在接收訊息時再次檢查來源網址。現有視窗限制提供前一道保護，仍建議評估增加來源檢查。這是補強建議，尚未證實可利用，不指定 CVSS 分數。 |
| 報告路徑 | ProjectReportStore 檢查檔案位於案件目錄，正式底稿發布不覆寫既有檔案；失敗時處理暫存檔與復原。 |
| 檢視限制 | 以上為指定範圍的閱讀與相關測試檢查，沒有據此宣告所有程式安全。 |

相關測試包括 TypedFieldCompilationTests、KeysetPagingTests、WebViewSecurityPolicyTests、ProjectReportStoreTests 與 ReportBatchPublicationTests。是否通過及涵蓋範圍以本次測試紀錄表為準。

## 4. 與 GitHub Security 的分工

| 工作 | 本機可做的部分 | 仍需另外完成 |

| 原始碼弱點分析 | security-audit 指引 Agent 檢視指定程式並記錄問題。 | CodeQL 的自動分析、查詢套件與結果追蹤。 |
| 套件漏洞 | NuGet 可查當下的公開漏洞資料。 | Dependabot 持續警示與版本更新追蹤。 |
| 機密資訊 | 可在明確範圍內檢查疑似密碼或金鑰。 | 秘密掃描、歷史紀錄掃描與推送保護；本次未執行。 |
| 修正與核准 | 可整理證據、修正紀錄及複測結果。 | 由公司指定人員判斷風險接受與部署條件。 |

專案已提供 security-audit 指引與 docs/security 目錄，目前沒有完整稽核的 run 紀錄。本次採有限範圍檢視，不能登記成已完成完整稽核，也不能視為已啟用 GitHub 的上述服務。
