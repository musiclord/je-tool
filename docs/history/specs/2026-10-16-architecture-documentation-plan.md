## 完成條件與驗證

- 原圖及 LikeC4 模型保持原始內容。LikeC4 離線 HTML 只把本機來源位置改為相對連結，入口明確顯示快照限制。
- 本機連結有效，離線閱讀不載入外部資源；可編輯模型和證據可從儲存庫找到。
- 關係檢查能拒絕種類不符、目標被換成未證實實作及無觀察紀錄的執行宣稱。
- Documentation 通過後完整回讀修改段落；提交前完成一次獨立複審。
- 原交接產品內容與圖表文件只有一個新增提交。修正失效連結後核對文件與提交內容，再推送到 origin/main。
- 本次文件修正不重跑產品建置、Public、Package、Gui、Excel、Provider 或 PrivateCase。先前驗證只代表各自收據記錄的內容。
